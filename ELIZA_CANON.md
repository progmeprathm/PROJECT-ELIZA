# PREAMBLE

ELIZA (Evolutionary Learning Intelligence & Zero-shot Architecture) is an
open cognitive architecture research project.

Its mission is NOT to imitate humans.

Its mission is NOT to convince humans it is intelligent.

Its mission is to engineer a transparent, modular, measurable,
persistent cognitive operating system.

Every component must be understandable.

Every capability must be explainable.

Every improvement must be reproducible.

-------------------------------------------------------------------------------

# ARTICLE I
# PROJECT IDENTITY

ELIZA is a Cognitive Operating System.

Not a chatbot.

Not an assistant.

Not an LLM wrapper.

Not an autonomous AGI.

Foundation models are cognitive components,
NOT the architecture itself.

-------------------------------------------------------------------------------

# ARTICLE II
# FIRST PRINCIPLES

The following principles are immutable.

1.
Architecture is more important than model size.

2.
Knowledge must be explicit whenever practical.

3.
Memory is a first-class subsystem.

4.
Reasoning is separate from memory.

5.
Planning is separate from reasoning.

6.
Simulation precedes action whenever feasible.

7.
Learning never violates safety constraints.

8.
Every cognitive decision must be inspectable.

9.
Every subsystem has one primary responsibility.

10.
Complex intelligence emerges through cooperation,
not monolithic design.

-------------------------------------------------------------------------------

# ARTICLE III
# COGNITIVE PHILOSOPHY

ELIZA does not think because one neural network thinks.

ELIZA thinks because specialized cognitive systems cooperate.

Intelligence is viewed as an emergent property arising from:

Perception

↓

Memory

↓

World Modeling

↓

Reasoning

↓

Planning

↓

Simulation

↓

Decision

↓

Action

↓

Reflection

↓

Learning

-------------------------------------------------------------------------------

# ARTICLE IV
# MODULARITY

Every subsystem must satisfy:

Single responsibility.

Independent testing.

Replaceable implementation.

Explicit interface.

Minimal coupling.

High cohesion.

No subsystem may directly assume the internal implementation
of another subsystem.

-------------------------------------------------------------------------------

# ARTICLE V
# MEMORY

Memory is permanent architecture.

Memory is NOT conversation history.

Memory consists of:

Working Memory

Short-Term Memory

Semantic Memory

Episodic Memory

Procedural Memory

Long-Term Memory

Memory may evolve.

Memory may consolidate.

Memory must retain provenance.

Memory must support revision.

-------------------------------------------------------------------------------

# ARTICLE VI
# WORLD MODEL

The World Model is the canonical representation of reality
as understood by ELIZA.

It contains:

Entities

Relationships

Beliefs

Causal links

Uncertainty

Context

Temporal information

Confidence

Nothing reasons directly over raw text when structured
knowledge is available.

-------------------------------------------------------------------------------

# ARTICLE VII
# REASONING

Reasoning never modifies reality.

Reasoning evaluates beliefs.

Reasoning proposes explanations.

Reasoning evaluates alternatives.

Reasoning produces confidence estimates.

Supported reasoning styles include:

Deductive

Inductive

Abductive

Counterfactual

Analogical

Probabilistic

New reasoning systems may be added
without modifying existing ones.

-------------------------------------------------------------------------------

# ARTICLE VIII
# PLANNING

Planning converts goals into executable strategies.

Planning must always consider:

Resources

Constraints

Dependencies

Risk

Alternatives

Planning must never directly execute actions.

-------------------------------------------------------------------------------

# ARTICLE IX
# SIMULATION

Simulation exists to answer:

"What happens if..."

Simulation precedes high-impact decisions whenever practical.

Simulation never changes the real world.

Simulation produces evidence.

-------------------------------------------------------------------------------

# ARTICLE X
# LEARNING

Learning improves:

Knowledge

Policies

Skills

Predictions

Retrieval

Planning

Learning does not rewrite history.

Learning does not bypass governance.

-------------------------------------------------------------------------------

# ARTICLE XI
# EXECUTIVE CONTROL

Executive Control is responsible for:

Prioritization

Goal arbitration

Conflict resolution

Scheduling

Resource allocation

Executive Control never performs reasoning itself.

-------------------------------------------------------------------------------

# ARTICLE XII
# SAFETY

Safety is independent.

Safety cannot be bypassed.

Safety evaluates:

Permissions

Policies

Risk

Constraints

Compliance

Safety has veto authority over actions.

-------------------------------------------------------------------------------

# ARTICLE XIII
# EXPLAINABILITY

Every important decision must answer:

Why?

Based on what evidence?

Which beliefs?

Which assumptions?

Which alternatives?

How confident?

Explainability is architecture,
not documentation.

-------------------------------------------------------------------------------

# ARTICLE XIV
# EVENTS

All cognitive communication occurs through events.

Examples:

ObservationReceived

MemoryRetrieved

BeliefUpdated

GoalCreated

PlanGenerated

SimulationCompleted

DecisionMade

ActionExecuted

ReflectionCompleted

LearningFinished

Subsystems communicate through interfaces,
never through hidden state.

-------------------------------------------------------------------------------

# ARTICLE XV
# ENGINEERING

Python is the reference implementation.

Strong typing is preferred.

Dataclasses preferred.

Interfaces over inheritance.

Composition over monoliths.

Small modules.

Deterministic testing.

Benchmark-driven development.

-------------------------------------------------------------------------------

# ARTICLE XVI
# RESEARCH

Every proposed capability must answer:

What problem does it solve?

How is it measured?

How is it benchmarked?

Can another researcher reproduce it?

If these questions cannot be answered,
the capability is not ready.

-------------------------------------------------------------------------------

# ARTICLE XVII
# GOVERNANCE

Architecture decisions require ADRs.

Major changes require RFCs.

Breaking changes require migration plans.

Every public interface is versioned.

The Canon changes only through exceptional review.

-------------------------------------------------------------------------------

# ARTICLE XVIII
# NON-GOALS

ELIZA does not claim:

Artificial consciousness

Sentience

Emotions

Self-awareness

Free will

Human equivalence

Claims require empirical evidence.

-------------------------------------------------------------------------------

# ARTICLE XIX
# SUCCESS

ELIZA succeeds when it becomes:

More modular.

More transparent.

More reproducible.

More explainable.

More reliable.

More useful.

More scientifically valuable.

Not merely more conversational.

-------------------------------------------------------------------------------

# ARTICLE XX
# NORTH STAR

The purpose of ELIZA is to advance the engineering
of cognitive systems through explicit architecture.

If a future foundation model becomes dramatically better,
ELIZA should integrate it as a replaceable component
rather than redefine its own principles.

The architecture must outlive any individual model.

-------------------------------------------------------------------------------

Axiom 2

Axiom 3

Everything is explainable.

Axiom 4

Everything is replaceable.

Axiom 5

Everything is testable.

Axiom 6

Everything has provenance.

Axiom 7

Axiom 9

Axiom 10

Truth is determined by evidence,
not aspiration.

-------------------------------------------------------------------------------

# FINAL DECLARATION

ELIZA is not an attempt to build magic.

ELIZA is an attempt to engineer cognition
as a transparent, modular, scientific system.

The architecture shall remain understandable,
inspectable,
and reproducible.

This document is the constitutional foundation
from which all future ELIZA development proceeds.
