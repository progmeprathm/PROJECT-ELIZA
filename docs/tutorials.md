# Developer Tutorials & Quickstart Guides

---

## 1. Running ELIZA Studio v0.1 Control Deck

To launch the web interface:
```bash
python run_eliza_studio.py
```
Open **`http://127.0.0.1:8000`** in your web browser.

Features to explore:
- Signature Live Panel inspecting active thoughts and confidence meters in real-time.
- Interactive SVG World Model graph renderer.
- Goal creation modal submitting goals directly to the ECOS Kernel.
- Simulator scenario sandbox running "what-if" counterfactual predictions.
